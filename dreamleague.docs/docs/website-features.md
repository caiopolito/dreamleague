# Website Features

## Authentication

Players log in via **Steam OpenID**. No account creation is required — your Steam profile is your identity. On first login, a player record is automatically created in the database.

## Lobby & matchmaking

The lobby is the central hub of DreamLeague. From here players can:

- **Join the queue** — enter the matchmaking pool. When enough players are queued, a match is automatically created and all players receive the server connection details
- **Chat** — a real-time overlay chat is available while in the lobby, powered by SignalR

## Teams

Players can create persistent teams and invite friends:

- Create a team with a custom name
- Send and receive team invitations (delivered via real-time notifications)
- View team members and manage the roster

## Championships

Admins can create and manage tournaments:

- Create a championship
- Register teams
- Track results and brackets

## Match history

Every completed match is stored and accessible from the **History** page:

- Full match details: teams, map, score
- Per-player stats: kills, deaths, assists, headshots, multi-kills

## Community

Browse all registered players on the platform.

## Profile

Each player has a public profile showing:

- Steam avatar and name
- Coins and points balance
- Match history
